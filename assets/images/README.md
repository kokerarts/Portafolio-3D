# Imágenes

Coloca aquí las imágenes que uses en el portafolio:

- `tu-foto.jpg` — tu fotografía de perfil (usada en `.hero-photo` dentro de `index.html`)
- Imágenes de tus proyectos — enlázalas luego desde `js/main.js` (tarjetas) y `js/project-detail.js` (galería e imagen principal)

Mientras no agregues imágenes propias, el sitio usa paneles decorativos con degradados como marcador de posición, así que funciona perfectamente desde el primer momento — no es necesario subir nada para verlo funcionando.
